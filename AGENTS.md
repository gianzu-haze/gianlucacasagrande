# Architecture

This is Gianluca Casagrande’s Italian portfolio, built with React 19, TypeScript, TanStack Start, file-based TanStack Router, Vite, and the Netlify Vite adapter. The requested scope is a presentation homepage and project collection. There is no authentication, database, contact form, or blog.

## Key files

- `src/routes/index.tsx`: homepage, original Italian biography, temporary geometric portrait alternative, and selected projects.
- `src/routes/projects.tsx`: nine projects with category filters and native expandable details.
- `src/lib/projects.ts`: authored project titles, category assignments, short factual summaries, and cover variants.
- `src/components/ProjectArt.tsx`: decorative CSS/SVG covers. They are explicitly identified as illustrative rather than real project screenshots.
- `src/components/SiteHeader.tsx`: shared navigation.
- `src/routes/__root.tsx`: Italian document, shared footer, accessibility skip link, metadata, and favicon.
- `src/lib/site.ts`: identity and shared metadata helper.
- `src/styles.css`: responsive editorial design, cream/terracotta/olive palette, typography, interaction states, and reduced-motion rules.
- `public/favicon.svg`: custom monogram favicon.

## Conventions and decisions

Keep public copy in Italian. Preserve supplied biography and project titles. Do not fabricate project outcomes, screenshots, external links, contact details, or experience. Full project stories have not been supplied; expandable cards acknowledge that they are in preparation. The homepage abstract composition is an explicitly temporary visual, approved by the user in place of a portrait.

Project content is authored source content, not runtime application state. No CMS or storage is necessary. If persistent editing or submissions are requested later, use Netlify platform storage. The starter’s unused content utilities/UI primitives remain available but the Content Collections plugin is not enabled.

Use typed Router Links for navigation, native semantic elements, visible focus states, and CSS Grid responsive layouts. Keep DOM-dependent logic out of SSR renders. Route trees are generated by TanStack tooling; do not edit generated files. No secrets are required. Do not add an og:image: the hosting platform supplies one.

## Local development

Use `pnpm install` and `pnpm dev` with Node 22.13+ or 24. Netlify emulation uses `netlify dev --port 8889`. The build pipeline validates production builds. Do not run build, test, typecheck, or dev-server commands in automated Netlify editing sessions when platform instructions prohibit them.
